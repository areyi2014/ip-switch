# 2026-09-07 工作日志

## ip-switch skill：消除"弹窗像病毒"问题（外行用户友好化）

### 问题
`node ~/.workbuddy/skills/ip-switch/scripts/open-ui.mjs aws` 在 Windows 下会让外行用户看到：
1. 自己 cmd 窗口里的 [INFO]/[OK] 日志（以为是后台程序）
2. spawn server.cjs 时 cmd 窗口一闪（以为是病毒）

### 解决：三层防线

1. **Layer 1（首选）—— 新增 `scripts/open-ui.vbs`**（Windows GUI 入口）
   - `WScript.Shell.Run "node ... --quiet", 0, False`（WindowStyle=0 隐藏 + 异步不阻塞）
   - 路径 `\` 转 `\\`（VBScript 字符串解析要求）
   - 自动启用 `--quiet`（避免 stderr 噪音）
   - 不创建桌面快捷方式（让用户自己右键"发送"→ 桌面）
   - install 用 `cp -R "$scripts_src/." "$dest/scripts/"` 整目录 copy，新文件**自动包含**——无需改 install

2. **Layer 2 —— `open-ui.mjs` spawn server 时自动检测 `nodew.exe`**
   - `path.join(path.dirname(process.execPath), 'nodew.exe')`
   - nodew.exe 是 Node 官方 Windows 安装包自带的 GUI subsystem 版本
   - 有则用之（彻底无 console），无则 fallback 到 `windowsHide: true`

3. **Layer 3 —— 加 `--quiet` / `-q` 选项 + 双写日志**
   - 默认：stderr + `<install-dir>/data/open-ui.log`（带 ISO timestamp）
   - `--quiet`：只写文件，stderr 完全静默
   - 实现用 **`fs.appendFileSync`**（同步写）—— 关键：不能用 WriteStream，进程立即 exit 时异步 flush 会丢日志
