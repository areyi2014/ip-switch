# 2026-09-02 工作日志

## install 脚本：用户级 [mcp_servers.ip-switch] 改由脚本幂等追加
- 问题背景：之前用户级 [mcp_servers.ip-switch] 只靠 CC Switch 自动合成（A 档）。CC Switch 没跑时，桌面版 Codex 的 MCP 列表看不到 ip-switch。
- 改动：
  - `install.ps1` 的 `Ensure-CodexUserConfig` 增加幂等追加 `[mcp_servers.ip-switch]` 段，用脚本级变量 `$script:CodexMcpNode` / `$script:CodexMcpDist` / `$script:installDir`（由 Install-CodexMcp 前置解析）。
  - `install.sh` 的 `ensure_codex_user_config` 同理，用全局 `$CODEX_MCP_NODE` / `$CODEX_MCP_DIST` / `$INSTALL_DIR`。
  - 两者均以 `Contains`/`grep -qF '[mcp_servers.ip-switch]'` 守卫：CC Switch 已写则跳过（避免重复表），未跑则补写。
- 验证：构造含现有内容的临时 config.toml，PowerShell 与 bash 两条路径各跑两次 → TOML 用 tomllib 解析通过，[mcp_servers.ip-switch] 仅出现一次（幂等确认），command/args/cwd/enabled 值正确。
- 项目级 / Profile 模板（ipSwitchConfigBody）仍不含 mcp 段，沿用上次"4 vs 3"修正。
